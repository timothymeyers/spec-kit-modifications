# Spec Kit Modifications

A general-purpose collection of amended Spec Kit skills, prompts, templates, and
workflow guidance. It provides:

- Better traceability across artifacts and items, including User Stories, Acceptance Scenarios, Functional and Non-Functional Requirements, Success Criteria, Clarifications, etc.
- `/speckit-closeout` skill that promotes specs to official 'living documents' in `docs/` that document the entire description of the system being built.
